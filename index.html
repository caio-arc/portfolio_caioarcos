PROJETO 08 • EVE-NG

Laboratório MikroTik — VLANs, DHCP, NAT e Firewall

Laboratório

Implementação prática em EVE-NG com MikroTik conectado a switches, utilizando VLAN 10, VLAN 20 e VLAN 30, gateways por VLAN, pools DHCP, cliente DHCP na WAN, DNS, NAT e regras de firewall.

Competências

VLAN, trunk, gateways, DHCP Server, DHCP Client, DNS, NAT masquerade, firewall filter, controle de comunicação entre VLANs e troubleshooting.

Endereçamento

VLAN 10: 192.168.10.1/24 • VLAN 20: 192.168.20.1/24 • VLAN 30: 192.168.30.1/24 • WAN: 192.168.136.129/24.

DHCP

Pools para VLAN 10, VLAN 20 e VLAN 30, com faixas .10–.254 e lease time de 30 minutos.

Configurações realizadas

/interface bridge add name=BR-TRUNK
/interface bridge port add bridge=BR-TRUNK interface=ether1
/interface vlan add interface=BR-TRUNK name=VLAN10 vlan-id=10
/interface vlan add interface=BR-TRUNK name=VLAN20 vlan-id=20

/ip address add address=192.168.10.1/24 interface=VLAN10
/ip address add address=192.168.20.1/24 interface=VLAN20

/ip pool add name=POOL-VLAN10 ranges=192.168.10.10-192.168.10.254
/ip pool add name=POOL-VLAN20 ranges=192.168.20.10-192.168.20.254

/ip dhcp-server add name=DHCP-VLAN10 interface=VLAN10 address-pool=POOL-VLAN10 disabled=no
/ip dhcp-server network add address=192.168.10.0/24 gateway=192.168.10.1 dns-server=8.8.8.8
/ip dhcp-server add name=DHCP-VLAN20 interface=VLAN20 address-pool=POOL-VLAN20 disabled=no
/ip dhcp-server network add address=192.168.20.0/24 gateway=192.168.20.1 dns-server=8.8.8.8

/ip dhcp-client add interface=ether1 disabled=no
/ip dns set servers=8.8.8.8,1.1.1.1 allow-remote-requests=yes
/ip dhcp-client set [find interface=ether4] use-peer-dns=no
/ip firewall nat add chain=srcnat out-interface=ether4 action=masquerade comment="NAT INTERNET"

/ip firewall filter add chain=forward connection-state=established,related action=accept comment="ACEITAR ESTABELECIDAS"
/ip firewall filter add chain=forward src-address=192.168.10.0/24 dst-address=192.168.20.0/24 action=accept comment="VLAN10 -> VLAN20 PERMITIR"
/ip firewall filter add chain=forward src-address=192.168.20.0/24 dst-address=192.168.10.0/24 action=drop comment="BLOQUEAR VLAN20 -> VLAN10"
/ip firewall filter add chain=input protocol=icmp action=accept comment="INPUT - ICMP"
/ip firewall filter add chain=input src-address=192.168.10.0/24 action=accept comment="INPUT - VLAN10"
/ip firewall filter add chain=input action=drop comment="INPUT - BLOQUEAR RESTANTE"

Evidências do laboratório

Resultado da implementação: VLAN 10 → VLAN 20 foi permitida; VLAN 20 → VLAN 10 foi bloqueada. Também foram configurados ICMP e gerenciamento pelas VLANs conforme as regras documentadas, além de NAT para saída pela interface WAN.

PRÁTICA 03

Configuração de Switch D-Link DGS-1210-28 e segmentação por VLAN

Vídeo demonstrando a configuração de um switch D-Link DGS-1210-28. O equipamento foi acessado inicialmente pelo IP de fábrica 10.90.90.90, utilizando uma máquina configurada com o IP 10.90.90.91. Após o acesso à interface web, foi configurado o IP fixo de gerenciamento 192.168.200.131 com máscara /22 e gateway 192.168.200.1. Também foram criadas e organizadas as VLANs 400 (Desktop LAN), 2000 (Gerência) e 2004 (Impressora). A porta 24 foi configurada como trunk, transportando as VLANs de gerência, impressora e Desktop LAN. A porta 1 foi definida como untagged para impressora, as portas 2 a 10 como untagged para a Desktop LAN e a porta 23 como untagged para a rede de gerência de segurança. Foram configurados os respectivos PVIDs e uma senha forte para proteção do equipamento.
